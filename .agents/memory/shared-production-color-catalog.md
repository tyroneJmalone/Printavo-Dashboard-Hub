---
name: Shared production color catalog
description: Cross-product ownership rule for Pantone, ink, thread, conversion, and stock data.
---

Printavo Hub and BreezyTweak should consume one shared production color catalog rather than maintaining separate copies. The source includes Pantone references, ink and thread mappings, HEX/CMYK/RGB conversions, and notations about which inks and threads are currently in stock.

**Why:** Operators need customer branding and artwork editing to agree on the exact same color and production-availability reference.

**How to apply:** Import and normalize the working spreadsheet into the shared catalog, then have each product reference catalog identities. Do not independently recreate or hand-maintain equivalent color rows in either product.
