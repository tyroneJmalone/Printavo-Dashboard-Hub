---
name: Cap America catalog direction
description: Intended unified search experience and better image source for the Cap America pilot.
---

The Cap America pilot is a starting point, not the intended final browsing experience. The user wants these products searchable and presented the same way as other vendors in the existing Catalog Search tab.

**Why:** On 2026-09-17 the user accepted the sample as a reasonable start but explicitly requested eventual unified catalog search/presentation.

**How to apply:** Extend the shared catalog experience rather than refining an indefinitely separate sample interface. Keep search/display support separate from live pricing, inventory, and ordering capability.

Prefer supplier product-page photos over PDF crops where verified. The i8501 product page exposes labeled blank front, back, and side photos plus decorated examples; two actual image responses measured 500×500 and 600×600, materially better than the roughly 190px PDF color images. The image gallery itself requires category interaction and was not verified as a bulk high-resolution download source.

**Why:** PDF extraction provided a quick pilot but sacrifices image quality and requires manual color mapping.

**How to apply:** Recheck https://www.capamerica.com/product/flexfit-performance-trucker-cap/i8501 and the user-supplied https://www.capamerica.com/imagegallery when expanding the sample. Validate actual image dimensions, style/color mapping, and blank versus decorated identity; do not infer original resolution from filenames.
