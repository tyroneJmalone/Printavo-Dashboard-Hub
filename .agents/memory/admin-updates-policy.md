---
name: Admin updates and planning library
description: User-approved release tracking and future-plan visibility conventions.
---

Keep a read-only, admin-only changelog and enhancement-document library in Settings.
Maintain user-facing release notes alongside future work. Distinguish prepared
changes from verified publications; backfilled summaries without verified dates
must remain historical, never assigned invented publish dates.

**Why:** The user loses track of what each publish includes and approved a shared
reference without creating another task-management system.

**How to apply:** Keep proposals separate from approved work and source existing
full documents rather than duplicate summaries as replacement plans. A curated
release label is not automatic deployment detection. See the maintenance guide
in docs/admin-updates-maintenance.md when updating content.
